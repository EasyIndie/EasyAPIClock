## 确定性规则

1. **固定时间**：使用 `2026-10-21T09:00:00+08:00` 这类字符串，不使用 `Date()` 或 `.now`。
2. **固定时区**：引擎内部固定北京时间；测试不修改 `TZ`。
3. **不睡眠**：不使用 `sleep`；异步测试只等待确定性的 async 调用。
4. **不联网**：更新测试使用内存 `RuleDataFetching` 假实现。
5. **不依赖仓库外文件**：规则端到端测试通过 `#filePath` 定位仓库 `Rules/`。
6. **数值类型**：可选 `TimeInterval` 与字面量比较时写成 `63 * 3600.0`，避免整数/浮点可选比较的歧义。

## 关键覆盖

### 时间与日历

- 工作日五个边界（08:59/09:00/12:00/14:00/18:00）与秒级边界。
- 周四/周五晚间的真实切换，不产生午夜伪切换。
- 周六/周日全天谷；调休周六仍为谷。
- 节假日覆盖优先于每周窗口；连续假期合并。
- 跨时区（UTC 输入）仍按北京时间。
- 当前窗口与下一窗口时长。
- coverage 过期、开始前、周末超出覆盖、下次切换越过覆盖。

### 规则包

- 仓库内置包可加载；模型/计费项数量、来源、覆盖、默认强度。
- 价格快照与官方核对值一致（改价格必须同时改测试与文档）。
- 篡改文件、缺文件、未声明文件、路径穿越、重叠假期、周末峰期、策略越界均拒绝。
- 远程更新：发现新包、同发布时间不更新、坏 checksum 拒绝、下载失败上抛、不安全文件名拒绝、HTTPS/OWNER 占位符配置。
- 本地安装：内置回退、未来生效进入 pending、到期提升、损坏回退。

### 提醒

- 中等只产生一个切换事件；关闭为空；提前提醒优先级与错过跳过。
- 强提醒重复次数与间隔有界；签名随强度/内容变化。
- 默认偏好为中等、提前关闭；规则更新不改变偏好编码。

### macOS 基础

- [ ] 菜单栏出现「峰/谷 · 剩余时间」，没有 Dock 图标，没有主窗口。
- [ ] 点击展开面板；再次点击或点击外部收起。
- [ ] 主面板显示状态名、带基准的价格行、倒计时、下一切换、日期摘要、提醒强度。
- [ ] 点击「设置」在同一面板切换；「完成」返回。
- [ ] 强度切换立即保存；重启应用后保持。
- [ ] 当前状态与 `liangwen-rules`/测试计算一致（可用北京时间核对）。

### 通知

- [ ] 首次启动出现通知权限请求；允许/拒绝后设置面板状态正确。

- [ ] 在真实边界（08:59/11:59/13:59/17:59）前等待，中等提醒只通知一次、短音一次。
- [ ] 强提醒重复通知，点击「停止提醒」后不再响；已送达通知被移除。
- [ ] 开启「提前 5 分钟」后，在边界前 5 分钟收到一次提前提醒；正式切换仍提醒。
- [ ] 关闭提醒后不再收到新通知；已排定的 pending 被取消。
- [ ] 应用面板关闭但进程仍在时，通知照常送达。
- [ ] 退出应用后，已排定通知的行为；重启后不重复补发。

## CI

`.github/workflows/ci.yml`：

1. **Rules + tests + lint**：校验内置规则包（含 checksum 与语义）→ `swift test` → `swift format lint`（与 CI 的 Xcode 16.4 / swift-format 600 配置兼容）。
2. **Build**：安装 `.xcodegen-version` 指定的 XcodeGen（SHA-256 校验）→ `doctor` → 生成工程 → 构建 macOS Debug（不签名）→ 检查 bundle 内 `Rules/manifest.json` → 构建 macOS Release 通用二进制（`arm64 + x86_64`，不签名）→ 构建 iOS 模拟器目标。
3. **Rules**（独立 workflow）：PR/主分支涉及规则或核心引擎时校验规则并跑测试；主分支通过后发布到 `rules` 分支，`publishedAt` 必须严格递增。

CI 不验证：真实通知、签名、公证、VoiceOver、通知中心外观、Focus/静音、睡眠唤醒。
