## 待集中处理的问题与限制

本轮按用户要求只验收并记录，没有修改产品实现。

1. **C2 通知端到端证据**：真实切换的中等横幅、强提醒重复与「停止」、退出后送达已通过；仍未验证实际听感、Focus/静音抑制对照、睡眠跨切换与系统改时/时区；用户已决定通知声音本轮保持系统默认，自定义声音后续再评估，且本机不做睡眠测试。系统 delivered 记录不作为用户看见/听见的唯一证据。
2. **C4 生命周期实机路径**：退出后送达、重启不补发已验证；睡眠跨切换、唤醒、手动改时/时区后的重算仍待执行（需用户同意影响会话或提供权限）。
3. **N2 登录启动未完成**：注册/取消和状态回读已验证；注销后重新登录自动启动未测。
4. **N4 减少动态效果未验**：外观选择和动效开关已有界面/持久化证据；macOS“减少动态效果”开启时逐项检查仍待完成。
5. **N6 定时监测已运行**：workflow 在默认分支，手动 observe 与两次每小时 schedule 均成功且 unchanged；新工作流注册后出现数小时调度延迟，属 GitHub 侧行为，未修改 workflow 语义或权限。真实价格变化时的候选 PR 流程仍待实际触发验证。
6. **N8 键盘/VoiceOver受系统条件限制**：只读AX可遍历；Tab焦点未推进，VoiceOver未开启。未改系统辅助功能设置，需在允许相应系统设置的验收窗口补测。
7. **N7 iOS仅构建通过**：未在模拟器验收界面运行；产品交互仍未定稿。
8. **macOS 13 arm64 缺设备**：`pro` 为 macOS 13.7.8 Intel；本轮无法提供 arm64 旧系统真机证据。
