## 待集中处理的问题与限制

本轮按用户要求只验收并记录，没有修改产品实现。

1. **C2 / N1 通知端到端证据不完整**：提醒计划和预览清理的自动化/系统记录通过；真实峰谷切换的横幅可见性、实际声音、中等/强提醒重复与停止交互尚未完成。系统delivered记录不代表用户看见或听见。
2. **C4 生命周期实机路径未验**：睡眠跨切换、唤醒、手动改时/时区后的重算和不补发历史仍待执行；避免通过改变系统时钟或让机器睡眠影响用户会话。
3. **N2 登录启动未完成**：注册/取消和状态回读已验证；注销后重新登录自动启动未测。
4. **N4 减少动态效果未验**：外观选择和动效开关已有界面/持久化证据；macOS“减少动态效果”开启时逐项检查仍待完成。
5. **N6 定时监测尚未在线运行**：解析测试与一次官方HTTPS unchanged观察通过；workflow需合并到默认分支后才开始按时调度，且创建草稿PR还受仓库Actions权限设置影响。
6. **N8 键盘/VoiceOver受系统条件限制**：只读AX可遍历；Tab焦点未推进，VoiceOver未开启。未改系统辅助功能设置，需在允许相应系统设置的验收窗口补测。
7. **N7 iOS仅构建通过**：未在模拟器验收界面运行；产品交互仍未定稿。
