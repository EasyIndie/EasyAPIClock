# 谷蹬：时间环与谷口

2026-10-27用户授权的视觉迭代。主要对象为macOS13+菜单栏应用，334×322pt；iOS仍是未确认设计的只读壳。

## 识别与图标

原创图标以蓝靛时间环、青绿谷口、暖珊瑚窗口节点构成，不使用DeepSeek商标或文字缩写。主面板直接显示DeepSeek API／峰谷价格提醒·北京时间，价格差异仍明确是模型单价，不扩展到Search/Fetch。规则卡含社区非官方说明。

图标由Scripts/generate-icon.swift原生路径绘制，make icon可重复生成16至1024像素资源，无额外运行时依赖。采用传统AppIcon兼容最低系统，不冒充Icon Composer分层材质。预览可直接打开Apps/Mac/Sources/Assets.xcassets/AppIcon.appiconset各PNG。

## 颜色角色

| 角色 | 浅色参考sRGB | 深色参考sRGB | 用途 |
|---|---|---|---|
| 品牌 | .20/.29/.70 | .61/.71/1 | DeepSeek定位标题、轻背景/hover |
| 谷期 | 0/.39/.35 | .40/.91/.81 | 低价状态文字与轻背景 |
| 峰期 | .61/.23/.09 | 1/.67/.51 | 高峰状态文字与轻背景 |
| 必要文字/说明/错误/选中 | 系统语义颜色 | 系统语义颜色 | primary/secondary/orange/controlAccentColor |

系统material仍是表面基准，低透明度渐变只作状态氛围层；减少透明度时不显示氛围层。普通控件继续尊重系统强调色，不把品牌色伪装成系统控件默认值。真实透明合成效果、VoiceOver及高对比仍与固色参考验证分开，不只凭色值宣称可访问性通过。

## 动效状态

- 主内容出现一次轻缩放/淡入，页面切换淡入淡出。
- macOS14+真实分钟数字变化使用numericText，13保留正常刷新，无秒数闪动。
- 折叠采用短spring与箭头旋转，hover/press轻反馈。
- 预览按钮仅在真实活动期间反馈，随停止/结束恢复。无永久背景循环，不伪造价格切换。
- 原gudeng.animations关闭或系统Reduce Motion开启时，不运行上述自定义运动。

## 展开内容对齐

| 内容 | 对齐与理由 |
|---|---|
| 开关/分段选择 | 左标签、右控件，同宽行便于操作与对照 |
| 操作解释与错误 | 靠左，自然阅读，不因居中削弱异常信息 |
| 自动尝试收据 | 居中且占全宽，表示同一自动检查的状态信息 |
| 规则身份/来源链接/非官方说明 | 居中，集中识别来源与关系 |
| 版本、覆盖与来源 | 键值两端对齐，值可选取，不把整段技术文字居中 |
| 价格/日历核对 | 对应两列，避免混淆不同核对日期 |

全部展开不承诺一屏显示全部信息，滚动容纳；固定标题与334×322边界不变，核心默认首屏仍完整。实际验收记录在../verification-2026-10-27/visual-refresh/；静态图、原生窗口截图、不可读帧分别标识。

Apple官方Motion/App icons在本轮通过DocC核验，原则与本项目具体参数分开；见ADR-0013。
