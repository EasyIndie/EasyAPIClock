## 主面板辅助功能文案复核

代码复核发现主面板原先用 durationPhrase 四舍五入朗读剩余时间，与画面及菜单栏的分钟向上取整不一致；不足一分钟也会朗读“一分钟”。已将合并朗读文案移入 ClockText，复用 compactRemaining：06:52:06 到09:00读“2小时8分”，08:59:01读“即将切换”。未知状态继续只读待确认及规则问题，不读精确倒计时。

## 自动更新过时失败反馈
