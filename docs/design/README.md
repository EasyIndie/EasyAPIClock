# 设计资料

## 视觉基准

[`../handoff/design-preview.html`](../handoff/design-preview.html)

用浏览器直接打开即可查看。页面自带一段模拟桌面与交互，仅用于审阅峰谷状态、面板层级、设置切换与提醒文案。

## 审阅方式

1. 在浏览器打开文件。
2. 点击顶部「谷 / 峰 + 剩余时间」展开或收起面板。
3. 点击「设置」调整提醒强度；点击「完成」返回。
4. 底部「预览」「模拟切换」是设计演示控件，**不属于正式产品**。

## 演示与真实的边界

设计稿只模拟：

- 峰谷场景、周末、节假日、规则缺失；
- 提醒卡片文案与关闭操作；
- 设置内容的布局。

它 **不包含**：

- 真实日期判断、真实节假日表、联网更新；
- 实际价格计算、倒计时推进；
- 声音、系统通知、后台运行、权限；
- iOS 页面；
- 完整可访问性验证。

正式实现的映射与差异见 [`../product/design-macos.md`](../product/design-macos.md)。

## 已知与实现不同的地方

- 原生使用系统浮层材质，不再额外套卡片阴影；
- 状态栏方向形状使用 SF Symbol；
- 强提醒使用系统通知，不是设计稿中的面板下方卡片；
- 规则有效性显示真实校验结果，不显示模拟「有效」徽章；
- 正式应用没有底部演示控件。
