# 谷蹬专属状态符号 · 设计探索

2026-10-26。设计提案，尚未替换运行版本；不是菜单栏截图。

## 产品依据

谷蹬回答“当前价格状态、距下次切换多久、何时提醒”。视觉识别应集中在价格相位与时间边界，而非天气、日夜、山景或方向导航。低价可能出现在白天，因此日月意象不适合作为主要身份。菜单栏文字继续提供峰/谷与剩余时间，符号负责一眼辨认和品牌记忆。

## 推荐 A：相位环

- 外环：时间周期；右侧断口与短刻度：切换边界。
- 内曲线：峰/谷价格相位；曲线极值处略加重，表达当前状态的落点。
- 圆环加价格曲线构成统一骨架，两态仍属于同一个品牌符号。
- 轮廓上拱为峰、下凹为谷；保留橙/绿与文字，黑白也可区分。
- 外环为静态识别结构，不是剩余时间进度条，不按百分比填充，不暗示真实价格走势。
- 不引入真实价格图表、装饰动画或新交互。

## 备选

B「时隙」：时间窗括号与高低价台阶，适合偏工程的定位，但品牌气质略硬。

C「谷弦」：峰谷曲线与当前落点，最简洁，但接近通用波形，独特性弱于A。
