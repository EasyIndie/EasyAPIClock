# ADR-0013：产品识别与可控的生动反馈

- 状态：已接受
- 日期：2026-10-27
- 依据：用户明确要求重做图标/配色、增加动效、突出DeepSeek定位并优化展开对齐。

以“时间环＋谷口”为原创标记，不复制DeepSeek鲸鱼商标。主面板常见位置显示DeepSeek API和峰谷价格提醒/北京时间，规则详情明确社区工具非官方。品牌蓝靛与价格状态的青绿/珊瑚分开，不替代系统强调色/错误色。

用户本轮请求覆盖早期“禁止装饰动效”的视觉限制，但仍不跳秒、不闪烁菜单栏、不制造价格事件或常驻窗口。增加有限入场、真实数字变化、页面切换、折叠和hover/press反馈；预览活动反馈仅在真实10秒预览期间运行。全部受原动效偏好和系统减少动态效果控制；减少透明度使用不透明系统背景。macOS13保留普通数字刷新，14+使用可用的numericText；不提高最低系统。

展开表单保持标签/控件两端对齐，解释和错误靠左；自动尝试收据可居中，规则身份/来源链接/社区声明居中，版本与日期按键值/对应列对齐。居中不应用到所有段落。面板仍334×322，所有展开状态可滚动。

Apple依据（2026-10-27已读取官方DocC）：https://developer.apple.com/design/human-interface-guidelines/motion ，https://developer.apple.com/design/human-interface-guidelines/app-icons 。运动应支持反馈、可选且简短；具体颜色、字号、时长和图标几何是项目选择。图标使用可复现原生路径生成的传统AppIcon以兼容13，不宣称已交付Icon Composer分层效果。iOS设计范围不变。
