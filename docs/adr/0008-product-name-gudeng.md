# ADR-0008：产品品牌采用「谷蹬」

- 状态：已接受
- 日期：2026-10-25
- 决策者：项目维护者

## 背景

原产品名「梁文钟」与 DeepSeek 创始人梁文峰的姓名高度相似；峰谷状态文案也曾使用「梁文峰 / 梁文谷」作为拟人化称呼。产品未来计划公开上架，需要降低个人姓名联想和官方关联误解，同时保留面向 AI 编程用户的轻松语气。

## 决策

1. 对外产品名为 **「谷蹬」**。
2. 产品副标题为 **「DeepSeek API 峰谷钟点提醒」**；品牌拼写统一使用官方写法 `DeepSeek`。
3. 峰谷状态改用功能性文案「高峰 / 低价」或「峰 / 谷」，不再以个人姓名作为状态别称。
4. 产品页面注明本项目为社区工具、与 DeepSeek 官方无隶属关系；DeepSeek 仅用于说明其价格规则来源与适用 API。
5. 原始 `docs/handoff/` 文件保留，不改写历史交接材料；当前品牌以 `docs/product/`、应用 UI 与发布材料为准。
6. 对外应用显示名、安装包文件名和发布 workflow artifact 名使用新品牌；仓库地址、Swift 模块、target、scheme 和生成工程名暂保留为技术标识。Bundle ID 仍为占位值，上架前按开发者控制的域名确认。

## 后果

- 品牌更短、聚焦低价时段，并保留「蹬 AI」社区用语的幽默感。
- 名称本身不能保证商标可注册或排除混淆；上架前仍须检索「谷蹬」及近似商标、应用名，并评估目标市场。
- 「蹬」偏网络口语；正式商店页面应通过副标题和功能描述清楚说明这是价格时段提醒工具，不是 API 网关或中转服务。
- 历史交接包和旧真机记录会保留旧称，且须明确视为历史材料。
