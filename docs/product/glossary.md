# 术语表

| 术语 | 含义 |
|---|---|
| 谷蹬 | 产品名。菜单栏 API 峰谷时段提醒工具；副标题为「DeepSeek API 峰谷钟点提醒」。 |
| 峰期 / 高峰时段 | 北京时间工作日 09:00–12:00、14:00–18:00（不含法定节假日）。 |
| 谷期 / 低价时段 | 非高峰时段，包括工作日其余时间、周末、法定节假日全天。 |
| 价格状态 | `peak` 或 `valley`；无法确认时为 `nil`，界面显示「待确认」。 |
| 切换 / transition | 价格状态真正发生变化的时刻，不是日期边界。 |
| 当前窗口 | 从上次切换到下次切换之间的一段连续状态。 |
| 日期覆盖 / coverage | 日历规则确认有效的日期范围，含首尾。超出范围的工作日无法确认。 |
| 日期例外 / override | 法定节假日等具体日期覆盖，优先级高于每周默认规则。 |
| 调休上班日 | 国务院安排中周末上班的日期。仅作记录；按官方峰谷文字，周末仍为谷。 |
| 规则包 / rule bundle | 一套完整规则：`manifest.json` + 价格 JSON + 日历 JSON + 提醒策略 JSON。 |
| bundleVersion | 规则包版本，由维护者按日期或序号递增；用于更新比较与展示。 |
| manifest | 规则包清单：文件列表、SHA-256、发布时间、生效时间。 |
| 生效时间 / effectiveFrom | 规则包开始适用的时刻。未来生效的包进入 pending。 |
| pending | 已下载并校验、但尚未到生效时间的规则包。 |
| 完整性校验 | 校验文件 SHA-256 与语义。**不是**数字签名。 |
| 回退 / fallback | 已安装规则无效时退回内置规则；网络失败时保留本地有效规则。 |
| 规则待更新 | 因覆盖不足、数据缺失或无效而无法确认价格状态时的降级状态。 |
| 中等提醒 | 默认强度：一次通知 + 一声短音，不循环。 |
| 强提醒 | 用户主动选择：有界重复通知，带「停止提醒」操作。 |
| 提前提醒 | 在切换前按策略偏移量（首版 5 分钟）发出的额外提醒，默认关闭。 |
| 本地偏好 | 用户选择的强度与提前提醒开关，存于 UserDefaults；远程更新不可覆盖。 |
| 提醒策略 / policy | 可更新的默认强度、提前偏移量、强提醒重复参数、声音开关。 |
| 事件 ID | 由切换时刻与类型派生的确定性标识，用于替换而非重复排程。 |
| 不补发 | 启动/唤醒/更新后只排未来事件，不集中发送历史通知。 |
| 规则工具 | `liangwen-rules` CLI：校验规则包、重算 manifest 校验和。 |
| 设计基准 | `docs/handoff/design-preview.html`，仅用于视觉与交互审阅。 |
| 交接包 | 2026-10-21 的原始产品/需求/设计/AI 输入文档，归档在 `docs/handoff/`。 |
