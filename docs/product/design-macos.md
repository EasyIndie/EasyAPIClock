# 已确认的 Mac 设计基准与实现映射

视觉基准：`../handoff/design-preview.html`（浏览器直接打开）。原始确认时间：2026-10-21。

本文描述 **已确认的视觉与交互**，以及它在原生 macOS 应用中的对应实现。网页稿的像素只是视觉参考，不是精确点值合同。

## 一、整体风格

小型原生风格面板：留白明确、少量分隔线、文字层级清楚。没有大插画、仪表盘、图表、完整价格表或装饰性动效。浅色 / 深色随系统外观变化；不只依赖颜色区分峰谷（同时有「高峰 / 低价」「峰 / 谷」文字）。

原生实现使用 `MenuBarExtra(.window)` 自带的浮层材质与阴影，**不再额外套一张带阴影的卡片**；这是与网页稿最明显的差异。

## 二、常驻状态栏

内容为方向形状、峰 / 谷文字、紧凑剩余时间，例如「⌄ 谷 · 2小时」或「⌃ 峰 · 4小时」。

实现：

- 方向形状使用 SF Symbol：`chevron.down`（谷）、`chevron.up`（峰）、`questionmark`（待确认）。
- 文字为 `谷 · 2小时` / `峰 · 4小时`；等宽数字。
- 按分钟或更粗粒度更新，避免秒数闪动和状态项宽度频繁变化。
- 规则不确定时显示 `规则待更新`。
- 图形仅表示价格状态，不表示自动切换模型。

紧凑时长规则：< 60 分钟显示「N分」（向下取整，最少 1 分）；< 24 小时显示「N小时」（四舍五入到最近小时，至少 1 小时）；更长显示「N天」或「N天N小时」。

## 三、主面板

参考宽度约 304pt；实现为固定 `.frame(width: 304)`。

| 区域 | 内容 | 实现 |
|---|---|---|
| 顶部 | 左侧「谷蹬」，右侧「设置」 | 12pt 次级文字 + 纯文字按钮 |
| 状态 | 「高峰」或「低价」 | 24pt、medium、字距 2 |
| 价格 | 「模型单价为谷期的 2 倍」或「模型单价较峰期低 50%」 | 13pt；峰用橙色，谷用绿色，未知用次级色 |
| 倒计时说明 | 「距离低价」或「距离高峰」 | 12pt 次级文字 |
| 倒计时 | 示例「02:00」 | 54pt 等宽数字；跨日改用 36pt 的「N天 N小时」 |
| 下一切换 | 「小时 : 分钟 · 14:00 切换」 | 12pt 次级文字；跨日只显示「周一 09:00 切换」 |
| 底部 | 日期类型简述与当前提醒强度 | 12pt；上方一条细分隔线 |

约束：

- 价格说明不能缩短成无基准的「半价」或含糊的「节省一半费用」。
- 主面板不重复显示当前时间，也不常驻提醒强度选择器。
- 跨日倒计时不挤进模糊的 `HH:MM`。
- 周末 / 假日显示「周末 · 全天低价」「国庆节 · 全天低价」；星期几用工作日细分（早间、上午高峰、午间、下午高峰、晚间）。
- 未知状态：状态名「待确认」，价格行显示具体规则问题，倒计时「—」，说明「更新规则后恢复价格提醒」，底部「提醒暂停」。

## 四、设置交互

点击「设置」后，同一个面板切换为设置内容；右侧按钮变为「完成」，点击返回。不新开偏好窗口，也不在主页下方无限展开。

仅保留：

- 提醒强度：关闭 / 中等 / 强，默认中等。
- 提前提醒：默认关闭；首版一个「提前 5 分钟提醒」选项（标签来自策略偏移量）。
- 简短强度说明。
- 规则来源、适用时区、规则包 / 价格 / 日期版本、覆盖范围、核对日期、来源链接。
- 检查规则更新入口与真实结果反馈。

网页示意中的「规则有效」是模拟标签。正式应用显示 **真实校验结果**：覆盖不足或日期未确认时用橙色显示问题；没有问题时展示覆盖范围与来源，不伪造一个「已验证」徽章。

设置底部另有一个弱化的「退出谷蹬」文字按钮。`LSUIElement` 菜单栏应用没有主菜单，缺少它会让用户无法正常退出；这是系统可用性补充，不属于功能扩张。

## 五、切换提醒

**中等：** 一次系统通知与一声短音。不持续占据主界面，不阻塞工作。重复通知不会排队。

**强：** 当前实现为有界重复的系统通知（默认 30 秒一次、最多 10 次，约 5 分钟），带「停止提醒」操作；停止后移除未送达的重复通知与已送达通知。没有独立浮层，也不默认抢焦点。

网页中提醒以面板下方卡片呈现，仅用于审阅文案和关闭操作，**不代表正式系统通知的位置、外观或权限能力**。正式应用没有这张卡片。强提醒打开后不应因用户关闭主面板而丢失停止入口——系统通知中心保留「停止提醒」操作。

## 六、特殊状态

| 状态 | 呈现与行为 | 实现 |
|---|---|---|
| 周末 | 低价、全天低价；持续谷期不每日重发提醒 | `dayKind == .weekend`；切换指向下一个工作日 |
| 法定节假日 | 低价、假日说明；按日期例外计算真正的下次变化 | `dayKind == .holiday(name:)` |
| 规则待更新 | 「待确认」、缺失说明、倒计时「—」；暂停无法确认的价格提醒 | `state == nil` 或 `nextChangeAt == nil`；`ReminderPlanner` 返回空计划 |
| 更新失败但旧规则有效 | 保持正常主界面；设置显示失败原因，不制造价格切换提醒 | `UpdateState.failed`；不触碰规则与计划 |
| 提醒关闭 | 状态显示继续工作；设置保存关闭偏好 | `ReminderIntensity.off`；取消 pending |

## 七、设计稿边界

已包含：状态栏展开 / 收起、设置切换、强度选择、场景切换、模拟峰谷变化、模拟提醒关闭。

**未包含**：真实时间推进、真实节假日表、联网更新、实际价格计算、提前提醒调度、系统通知、声音、后台运行、可访问性完整验证或真实原生适配。

底部「预览」「模拟切换」及示例说明是审稿辅助，正式应用必须移除。页面中的两个示例按钮与场景选择器没有进入应用。

## 八、实现差异与未决项

| 项 | 网页稿 | 原生实现 | 说明 |
|---|---|---|---|
| 面板外观 | 卡片 + 阴影 | 系统浮层材质 | 尊重原生菜单栏交互 |
| 状态图形 | `⌄` / `⌃` 字符 | SF Symbol | 字体覆盖更稳定 |
| 强提醒 | 面板下方卡片 | 系统通知 + 停止操作 | 呈现方式待设备验证；可能改为浮层 |
| 规则有效性 | 模拟「有效」 | 真实覆盖/版本/来源 | 不伪造徽章 |
| 声音 | 未接入 | 系统默认通知声 | 受静音/专注模式影响 |
| 图标 | 无 | 峰谷分色时钟图标（AppIcon 1024pt 全套） | 由 `Scripts/generate-icon.sh` 生成；深色圆角底，左橙右绿，指针指向 09:00 |

| iOS | 未设计 | 只读外壳 | 不代表正式设计 |

## 十、2026-10-26 改版迭代

本轮以用户提供的 `gudeng-design/谷蹬-设计方案.md` 与主面板、设置图片为新视觉参考，替代前文的 304pt 面板布局：固定 334×322pt，主页移除顶部品牌栏，使用大号「谷期 / 峰期」、倒计时、价格基准和底部真实切换时间；跨日显示北京时间日期。右下角齿轮原位进入设置，固定标题和返回入口，只有内容滚动。外观支持系统 / 浅色 / 深色并即时持久化；动效开关默认开启，尊重减少动态效果；减少透明度时使用不透明背景。菜单栏使用下凹谷线 / 上凸峰线，小时保留分钟，不足一分钟显示「即将切换」。

冲突处理：新稿中图标为未确认概念板，不替换现有正式图标；强提醒继续遵循 ADR-0005 的有界系统通知，不引入无限响铃。iOS 继续保留只读验证外壳。价格与日历未改变，设计示例不是规则来源。

本轮尚未实现设计提议中的提醒预览、登录时启动、自动更新规则开关及新图标矢量资源；这些新增交互需要后续补齐需求与平台验证。设置滚动位置保留、底部渐隐、打开面板动效、原生截图和录屏也尚未验收。

### 截图验收后的细化

- 设置行统一左侧标签、右侧控件；显示模式隐藏 Picker 内置标签，避免重复挤压；提前提醒与动效开关靠右对齐。
- 菜单栏与主面板统一向上取整到分钟；不足一分钟均显示「即将切换」，避免相差一分钟或显示 00:00。
- macOS 菜单栏图形由原生 NSImage 承载，避免 MenuBarExtra 忽略 SwiftUI Path；谷为下凹曲线、峰为上凸折线。
- 主状态使用浅色深绿 / 深琥珀与深色薄荷绿 / 明琥珀；设置显式请求显示系统滚动指示器，实际可见性仍受系统滚动条偏好控制。

### 外观覆盖修复

MenuBarExtra 中仅设置 preferredColorScheme 未能改变实际呈现。面板现在显式传递 SwiftUI colorScheme，并通过 macOS 原生视图将所属面板 appearance 设为 Aqua / Dark Aqua；选择「系统」时清除原生覆盖并继续继承环境。覆盖仅作用于谷蹬面板，不修改系统外观。

### 设置三项补齐

提醒组增加「预览提醒」与独立结果文案，运行中按钮变为「立即停止预览」；关闭强度禁用预览。预览权限不足时如实说明，可沿用通知权限系统入口。离开设置立即停止预览。

通用组增加「登录时启动」与「自动更新规则」右侧开关。登录启动从系统读真实状态，审批中明确提示并提供系统入口；失败显示原因。自动更新默认开启，说明每6小时最多自动尝试一次，手动更新入口保留。所有新增内容仍在同一个固定尺寸滚动区域，设置即时生效。

### 设置详情页UI审阅与优化

2026-10-26实测窗口334×322pt，标题/返回在滚动前后相对位置一致；个别截图标题缺失与实时AX几何矛盾，属于捕获/合成不一致，不认定为稳定产品布局缺陷。实现显式保持46pt标题、1pt分隔和275pt滚动区并裁切滚动内容。

设置拆分为提醒、外观、通用三组，统一28pt最小行高、右侧控件对齐与11pt组标题。减少常驻说明，强度说明可悬停查看；预览运行时左侧明确显示「立即停止预览」。规则元数据默认折叠为「规则信息＋包版本」，展开仍在原位滚动；日期覆盖问题、坏规则回退与待启用提示不随详情折叠隐藏。来源链接使用明确链接色。退出位于滚动内容末尾。

图标按钮在Label内部设置完整点击区域：返回28×32pt、设置32×36pt、预览28×28pt；保持可访问性文本标签，不只依赖图形。

辅助功能：主面板合并朗读状态、价格基准与剩余时间；剩余时间沿用可见倒计时向上取整，不足一分钟读“即将切换”；未知状态不朗读精确剩余时间。

菜单栏峰谷状态图标：用户选定SF Symbols候选C。21×16pt占位内等比例绘制 `arrow.up.circle.fill`（峰，系统橙色）与 `arrow.down.circle.fill`（谷，系统绿色），Semibold、单色填充。箭头代表当前高／低价状态，配合峰／谷文字，不代表价格持续涨跌。未知状态保持问号。图标通过公开NSImage系统符号API生成，不引入第三方运行时；亮暗离屏预览见 `docs/design/menu-bar-icons/README.md`。


## 2026-10-26 时长语义与菜单栏对齐修订

主面板不再将剩余时长写作HH:mm，避免与底部的真实时刻混淆。使用“11小时16分”“2小时”“45分”；分钟继续向上取整，整小时不补零分，超过一天沿用天/小时，不足一分钟为“即将切换”，未知为“—”。数字52pt semibold、单位18pt medium共用基线，单行72pt高区域，长内容可缩小；下方文字为“后进入峰期／后进入谷期”。334×322pt外框和底部真实切换时刻不变。iOS只读壳复用文案，不增加交互。

菜单栏保留实心圆上/下箭头与橙/绿色，直接使用原生SF Symbol配置，不再绘入自定义21×16画布，保留符号排版信息；图文按firstTextBaseline布局。参考Apple官方SF Symbols设计资源（2026-10-26核对入口：https://developer.apple.com/design/human-interface-guidelines/sf-symbols ；页面正文抓取受限，不据此宣称HIG规定具体点值）。实际对齐与视觉效果以原生验收记录为准。


## 2026-10-26 紧凑设置分组

固定标题和334×322pt外框不变，首屏常驻提醒强度、提前提醒、预览三行。移除重复的提醒分组标题和闲置时的预览说明，完整解释仍在help中；预览运行时保留有界次数/停止说明，失败与权限拒绝即时显示。

外观、通用、规则信息默认折叠；展开外观后显示显示模式与动效，展开通用后显示登录启动、自动规则检查和说明，规则元数据保持原位展开。折叠状态仅属当前设置页面，不改变用户业务偏好。检查规则更新和退出入口常驻内容末尾，同一行展示，展开后可滚动到达。规则缺失、坏下载、pending、更新失败、登录审批或注册错误不因折叠隐藏；临时安装不可用说明留在通用组内。默认正常状态首屏可完整容纳全部核心行、分组和底部动作；异常文字或展开内容允许滚动，不压缩到不可读。


### 2026-10-26 精确对齐补验

上一轮菜单栏目测通过不足以证明视觉中线对齐。对2×真实截图逐像素量测，圆形图标中心比“谷”中文字形中心低2px（1pt）。实机证明MenuBarExtra忽略NSImage alignmentRect偏移，故保留原生符号来源、颜色与20pt原尺寸画布，在画布内把可见内容上移1pt；以实际MenuBarExtra截图量测验证，不能用HStack基线或元数据声明代替证据。

提醒强度和外观分段选择器移除SwiftUI Picker的174pt固定外层。窗口级稳定截图证明，SwiftUI桥接可能报告129pt布局框却绘出更宽的原生控件，且首帧与稳定态会变化；自然宽度和4pt手工补偿均未可靠解决。最终由SettingsSegments薄适配器直接承载系统NSSegmentedControl，实际frame150×24pt、alignmentRectInsets归零、fillEqually均分三段；SettingsRow占满宽度并用Spacer实现左右布局。只映射现有Binding，不另存状态、不改变偏好键或业务流程；iOS保留SwiftUI Picker编译分支。

2026-10-27继续补验：真实2×菜单截图中圆形y6…38、谷字y11…33，中线均为22px，差0px。原生控件适配器的设置结果见precision-alignment目录最终截图及测量记录。

最终窗口级验收：delivery-settings与delivery-appearance的分段bezel右边缘均为627px，与内容边界627px差0px；AX三段均50pt，完整圆角无裁切。此结论对应SettingsSegments系统原生适配器，不对应先前失败的SwiftUI Picker调边距试验。

## 2026-10-27 安装版设置功能反馈

日常启动入口为应用程序中的谷蹬.app。登录项notFound不再被误判为不可注册；开关只在用户操作后register/unregister，错误与审批信息保持可见。外观将“动效”明确为“页面切换动效”，展开后说明仅控制主面板/设置淡入淡出及减少动态效果优先。两页面显式opacity过渡，不改变尺寸或引入装饰动画。通用自动更新区新增最近一次尝试的北京时间记录，失败也记录、手动不改，默认折叠不增加首屏占用。预览仍是系统通知，未授权失败不伪造成功，投递与用户实际看到/听到须分别取证。
