# 产品概览

## 定位

谷蹬是一款极简的 **API 价格时段时钟**，帮助使用 DeepSeek API 的开发者判断当前模型调用价格处于高峰还是低价时段，并在切换时及时获得提醒。

它只回答三个问题：

1. 现在贵还是便宜？
2. 距离下次切换还有多久？
3. 切换时如何提醒我？

它不是账单工具、用量分析器、模型路由器或任务调度器。

## 对外表达

- 产品名：**谷蹬**。
- 副标题：**DeepSeek API 峰谷钟点提醒**。
- 状态文案使用「高峰 / 低价」或「峰 / 谷」，不使用个人姓名作时段别称。
- 「谷蹬」是社区工具名称，与 DeepSeek 官方无隶属关系；价格以官方页面为准。
- 不说「全部 API 费用减半」：Search / Fetch 独立按次计费，不在模型 Token 单价规则内。
- 不承诺跨时段请求锁价；官方页面未明确跨越切换时刻的请求按哪个时点判价。

## 首版体验

macOS 常驻菜单栏，显示「峰 / 谷 + 距离下一次切换的时间」。点击展开紧凑面板：峰谷名称、模型单价差异、倒计时、下一切换与日期摘要。系统菜单栏已有当前时间，面板不再重复大时钟。

切换时默认一次通知加短音。用户可关闭提醒，或选择需要手动停止的强提醒。持续显示安静，价格切换明确。

首版同时面向 macOS 与 iOS，但 **只有 Mac 界面经过确认**。iOS 沿用相同产品范围与规则语义，页面与通知能力另行设计、验证；当前仓库中的 iOS 应用只是验证共享引擎的外壳。

## 范围

必须有：

- 当前状态与下次切换倒计时
- 本地提醒与提醒强度设置
- 可选提前提醒（首版提前 5 分钟）
- 内置离线规则
- 联网规则更新与日期覆盖说明
- 规则来源、版本、有效性与更新入口

不加入：

- 番茄钟、专注计时器
- 账号、API Key、Token 用量统计、消费分析
- 任务管理、Agent 集成
- 任务自动暂停或模型自动切换
- 主界面完整价格表或复杂日历
- 硬件配网/设备管理

未来可扩展到 ESP 实体时钟，复用规则语义、峰谷状态和切换事件；本阶段只保留语义，不实现硬件功能。

## 更新原则

- **价格规则**决定什么时候是什么价格。
- **提醒策略**决定在什么阶段使用什么提示。
- **通用机制**按策略执行，调用平台通知能力。
- **用户偏好**决定允许的提醒强度，远程更新不能覆盖。

内置规则保证离线可用；更新失败保留有效旧版本。影响当前状态判断的数据缺失或过期时，显示待更新并暂停无法确认的价格提醒，不伪装成准确状态。

## 成功标准

- 用户无需阅读说明，就能看出当前贵或便宜、下一次变化何时发生。
- 切换提醒明确且强度可控。
- 界面保持极简。
- 价格和日期规则变化可以通过数据更新处理，而不必发版改代码。
