# 梁文钟｜已确认的 Mac 设计基准

基准文件：`design-preview.html`。原始设计确认时间：2026-10-21。

## 一、整体风格

小型原生风格面板，留白明确、少量分隔线、文字层级清楚。没有大插画、仪表盘、图表、完整价格表或装饰性动效。浅色 / 深色随系统外观变化；不只依赖颜色区分峰谷。

## 二、常驻状态栏

内容为方向形状、峰 / 谷文字、紧凑剩余时间，例如“⌄ 谷 · 2小时”或“⌃ 峰 · 4小时”。这些图形表示当前价格状态，不表示自动切换模型。正式图标可用对应的原生图形，最终图标资产尚未定稿。

按分钟或更粗粒度更新，避免秒数闪动和菜单项宽度频繁变化。倒计时用等宽数字。规则不确定时改为“? 规则待更新”。点击展开 / 收起面板。

## 三、主面板

设计参考宽度约 304pt；网页稿的像素为视觉参考，不作为原生实现精确点值合同。

| 区域 | 内容 | 层级 |
|---|---|---|
| 顶部 | 左侧“梁文钟”，右侧“设置” | 弱化，不与主要状态争夺注意 |
| 状态 | “梁文峰”或“梁文谷” | 约 24 大小、居中 |
| 价格 | “模型单价为谷期的 2 倍”或“模型单价较峰期低 50%” | 约 13 大小；峰用暖色，谷用柔和绿色 |
| 倒计时说明 | “距离低价”或“距离高峰” | 次级文字 |
| 倒计时 | 示例“02:00” | 约 54 大小，等宽数字，视觉重点 |
| 下一切换 | “小时 : 分钟 · 14:00 切换” | 次级文字 |
| 底部 | 日期类型简述与当前提醒强度 | 约 12 大小，单条细分隔线 |

价格说明不能缩短成无基准的“半价”或含糊的“节省一半费用”。主面板不再重复显示当前时间，也不常驻提醒强度选择器。

正式倒计时支持跨日长度，不把超过 24 小时的时间挤入模糊的 HH:MM。周末 / 假日的“全天低价”示意应在真实规则完整时配合准确的下次切换信息；不能用网页模拟文案替代状态计算。

## 四、设置交互

点击“设置”后，在同一个小面板中切换为设置内容；点击“完成”返回。不是在主面板下不断展开更多内容，也不另开大型偏好窗口。

仅保留：

- 提醒强度：关闭 / 中等 / 强，默认中等。
- 提前提醒：默认关闭；首版一个“提前 5 分钟”选项即可。
- 简短的强度说明、规则来源、适用时区、规则版本 / 更新时间 / 有效性。
- 检查规则更新入口及结果反馈。

网页示意中的“规则有效”是模拟标签，正式应用必须由真实校验结果驱动。策略可以更新，但不增加面向普通用户的复杂编辑器。

## 五、切换提醒

中等提醒：一次系统通知和一声短音，不持续占据主界面，不阻塞工作。

强提醒：在 Mac 上显示醒目提醒与持续提示，具有“停止提醒”操作。是否采用独立浮层或其他原生呈现方式，需在系统能力验证后确定；不会默认抢焦点或修改其他应用状态。

网页中提醒以面板下方卡片呈现，仅用于审阅文案和关闭操作，不代表正式系统通知的位置、外观或权限能力。声音没有接入。强提醒打开后不应因用户关闭主面板而丢失停止入口。

## 六、特殊状态

| 状态 | 核心呈现与行为 |
|---|---|
| 周末 | 梁文谷、全天低价；持续谷期不每日重发提醒 |
| 法定节假日 | 梁文谷、假日说明；按日期例外计算真正的下次变化 |
| 规则待更新 | “待确认”、缺失说明、倒计时“—”；暂停无法确认的价格提醒 |
| 更新失败但旧规则有效 | 保持正常主界面，设置中显示更新失败，不故意制造价格切换提醒 |
| 提醒关闭 | 状态显示继续工作，设置保存关闭偏好 |

## 七、设计稿边界

已包含：状态栏展开 / 收起、设置切换、强度选择、场景切换、模拟峰谷变化、模拟提醒关闭。

未包含：真实时间推进、真实节假日表、联网更新、实际价格计算、提前提醒调度、系统通知、声音、后台运行、可访问性完整验证或真实原生适配。

底部“预览”“模拟切换”及示例说明是审稿辅助，正式应用必须移除。页面无需联网即可演示，不包含账号或密钥。

iOS 没有已确认的视觉稿，不得将本文件描述成 iOS 已设计完成。硬件展示同样属于未来方向。
