## 价格复核（2026-10-23）

重新访问 <https://api-docs.deepseek.com/zh-cn/quick_start/pricing/>，核对结果与 2026-10-21 交接包一致：

- `deepseek-flash`：缓存命中 0.02 / 0.04；未命中 1 / 2；输出 4 / 8。
- `deepseek-v4-pro`：缓存命中 0.15 / 0.30；未命中 4.5 / 9；输出 13.5 / 27。
- 工作日 09:00–12:00、14:00–18:00 为峰；其余（含周末、法定节假日）为谷。
- 谷期为峰期一半；Search / Fetch 独立按次计费。
- 官方页面另提示：2026-11-01 起，在部分工具中通过服务端访问 Search/Fetch 将按次收费。这不属于模型 Token 倍率。

数据写入 `Rules/pricing.json`，`source.checkedAt` 记录为 2026-10-23。

## 解释性决策

原始交接包没有逐条规定实现细节，以下为整理时做出的显式决策：

1. **技术栈**：Swift 6 + SwiftUI + SwiftPM 核心（原始文档未定稿）。
2. **iOS**：只做只读外壳，避免发明未确认的设计。
3. **日期数据**：使用单文件、单一 coverage；2027 年发布后扩展同一文件或改名并在 manifest 中声明。
4. **强提醒**：首版使用有界重复通知 + 停止动作；不实现独立浮层。
5. **规则完整性**：SHA-256 + 语义校验；数字签名列为后续工作。
6. **中文优先**：首版不做英文界面，文案集中以便迁移。
7. **验收状态**：在 `../product/requirements.md` 中区分“已自动化验证”“需真机”“未实现”，不把设计稿视为已通过。

## 设计稿的模拟元素

`design-preview.html` 是审阅工具，不是生产实现：

- 不进行真实日期判断，不读取官网；
- 不播放声音，不发系统通知；
- 倒计时不实时运行；
- 提前提醒、检查更新仅为示意；
- 底部「预览」「模拟切换」及场景选择器不进入正式应用；
- 页面引用了外部 CDN 资源，离线打开时交互可能不完整。
