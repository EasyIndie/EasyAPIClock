# 梁文钟｜AI 开发交接包

设计基准版本：2026-10-21 · 第一版需求与设计交接

这份交接包汇总本轮已确认的产品计划、需求、价格与提醒策略、Mac 交互设计及开发代理输入。它是设计交接材料，不是已经实现的应用。

## 阅读顺序

1. `01-product-plan.md`：定位、用户价值、首版边界。
2. `02-requirements-and-rules.md`：功能需求、规则更新、日历判断、验收场景。
3. `03-design-spec.md`：已确认的 Mac 界面与交互。
4. `04-agent-prompt.md`：可直接交给 AI 开发代理的任务输入。
5. `design-preview.html`：浏览器打开即可体验的交互设计稿，不需要安装依赖。

## 当前决策

- 产品名：梁文钟；时段趣味名称：梁文峰 / 梁文谷。
- 对外只介绍 API 峰谷定价灵感，不介绍人名来源。
- 首版平台：macOS 和 iOS；本轮只完成 Mac 状态栏设计，iOS 页面尚未设计。
- Mac 形态：常驻状态栏，点击展开小面板；默认中等提醒，可选择关闭或强提醒。
- 最新的简洁设计稿是唯一视觉基准，不回退到早期信息较多的版本。
- 价格规则与提醒策略可分别更新；用户提醒强度由本地偏好决定。
- 当前没有实现、仓库初始化、提交、部署或真实通知接入。

## 使用设计稿

点击顶部“谷 / 峰＋剩余时间”可展开或收起；点击“设置”可调整提醒强度；点击“完成”返回主面板。底部“预览”和“模拟切换”属于设计演示控件，不属于正式产品。

设计稿只模拟峰谷、周末、节假日、规则缺失和提醒视觉，不进行真实日期判断，不读取官网，不播放声音，不发送系统通知。倒计时不是实时运行，提前提醒是选项示意，检查更新是入口示意。不要把这些模拟能力当成已完成的功能。

产品范围以本交接包的文字需求为准；视觉与布局以 `design-preview.html` 为准；实时价格与计费定义以 DeepSeek 官方来源为准。发现冲突应记录并解决，不直接沿用模拟数据。
