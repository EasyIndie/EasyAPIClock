# 梁文钟｜极简产品计划

## 定位

梁文钟是一款极简的价格时段时钟，灵感来自 API 峰谷定价。它帮助使用 DeepSeek API 的开发者快速判断当前模型调用价格处于高峰还是空闲，并在价格切换时明确感知“开始更省”或“开始更贵”。

它只回答三个问题：现在贵还是便宜、距离下次切换还有多久、切换时如何提醒我。

## 首版体验

Mac 端常驻状态栏，显示“峰 / 谷＋距离下一次切换的时间”。点击后展开紧凑面板，显示峰谷名称、模型单价差异和倒计时。系统菜单栏已有当前时间，面板不再重复放置大时钟。

切换时默认一次通知加短提示音。用户可关闭提醒，或选择需要手动停止的强提醒。持续显示应当安静，价格切换应当让用户明确感知。

首版同时面向 macOS 和 iOS，但本轮只确认了 Mac 界面；iOS 沿用相同产品范围与规则语义，具体页面及通知能力另行设计、验证。

## 范围

必须有：当前状态、下次切换倒计时、本地提醒、提醒强度设置、可选提前提醒、内置离线规则、联网规则更新、日期例外与规则有效性说明。

不加入：番茄钟、专注计时器、账号、API Key、Token 用量统计、消费分析、任务管理、Agent 集成、任务自动暂停或模型自动切换。主界面不展示完整模型价格表或复杂日历。

## 更新原则

价格规则决定什么时候是什么价格；提醒策略决定在什么阶段使用什么提示；通用提醒机制按策略执行；用户偏好决定允许的提醒强度。规则与策略更新不能擅自提高用户设置的强度。

内置规则保证离线可用，更新失败保留有效旧版本。对影响当前状态判断的数据缺失或过期，显示待更新并暂停无法确认的价格提醒，不伪装为准确状态。

## 未来硬件

未来可扩展到 ESP 实体时钟，复用规则语义、峰谷状态和切换事件。硬件可把提醒映射到灯光或蜂鸣器，但本阶段不实现硬件配网、设备管理或手机联动。

## 成功标准

用户无需阅读说明，就能看出当前贵或便宜、下一次变化何时发生；切换提醒明确且强度可控；界面保持极简；价格和日期规则变化可以通过数据更新处理。
